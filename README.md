## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Whitelist Manager** | Add or remove blocks from the Ore Excavator mining whitelist |
| **Depth Limit** | Set maximum excavation depth to prevent runaway digging |
| **Count Limit** | Configure maximum blocks per excavation action |
| **Safe List** | Mark fragile or rare blocks as protected from accidental excavation |
